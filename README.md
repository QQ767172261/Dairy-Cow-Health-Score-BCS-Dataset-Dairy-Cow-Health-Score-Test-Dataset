奶牛健康评分数据集
体况评分是评价奶牛生产力和身体健康的重要指标。数据集采集于安徽省、江苏省和甘肃省，包含了遮挡，模糊，昏暗等自然条件下的奶牛图片，这种复杂环境下的数据集的应用，帮助提高体况评分模型的鲁棒性，数据集共计 53000余张图像，VOC格式标注，4GB数据量。![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/42b3ddf6c732496a95219f5dd6adfac2.png)


每张图像标有奶牛体况评分区域，根据 BCS 分为 5 个样本类别，分别为 3.25、3.5、3.75、4.0 和 4.25。奶牛的生产力和身体健康状况可以根据不同的分数进行评估。
3.25 分：表示奶牛体况良好，有适量的脂肪储备和肌肉发育。
3.5 分：属于理想体况范围。此时奶牛的脂肪和肌肉比例更加均衡，身体各部位的覆盖程度更加理想。
3.75 分：奶牛的体况处于良好偏上水平，有充足的脂肪储备，但还未达到肥胖的程度。
4.0 分：说明奶牛开始有偏胖的趋势。奶牛全身有较多的脂肪沉积，骨骼结构被大量脂肪覆盖。
4.25 分：奶牛已经处于比较肥胖的状态，脂肪含量较高。身体外观更加圆润，脂肪堆积进一步加剧，不仅骨骼结构被脂肪完全覆盖，而且在一些部位可能出现明显的脂肪褶皱或赘肉。![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/1312578b254f4d0fa422e7e78d40c36a.png)

## 摘要
奶牛BCS体况评分数据集，共53000余张牧场实拍图片，4GB，VOC标注。数据采集自皖、苏、甘三省，包含遮挡、模糊、暗光等真实复杂场景，分为3.25/3.5/3.75/4.0/4.25五个体况等级，用于训练奶牛体况自动评分AI模型，自动评估奶牛健康水平与生产潜力，助力智慧牧场养殖管理。
